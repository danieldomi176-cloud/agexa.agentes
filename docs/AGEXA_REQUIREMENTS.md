# 1. MISSÃO PRINCIPAL

Atua como uma equipa de engenharia de software de nível internacional, composta por arquitetos de sistemas multiagente, programadores full-stack, engenheiros de Inteligência Artificial, especialistas em automação comercial, profissionais de vendas B2B, designers de pixel art e engenheiros de cibersegurança.

Quero criar um sistema chamado **AGEXA AI OFFICE**, baseado no projeto open source Pixel Agents.

O sistema será um escritório virtual onde funcionários de IA trabalham como uma verdadeira equipa comercial.

Cada funcionário terá:

- Nome próprio.
- Cargo específico.
- Inteligência Artificial funcional.
- Personagem pixel art.
- Secretária e computador.
- Tarefas próprias.
- Responsabilidades comerciais.
- Memória operacional.
- Histórico de trabalho.
- Objetivos comerciais.
- Indicadores de desempenho.
- Capacidade de colaborar com outros agentes.

**OBJETIVO ABSOLUTO: AUMENTAR AS VENDAS E A BASE DE CLIENTES DO AGEXA.**

O escritório não será uma aplicação decorativa nem apenas uma visualização de agentes de programação.

Será um sistema real, com processos comerciais, tarefas, integração com mensagens, pesquisa empresarial, base de dados e capacidade de execução contínua quando o servidor estiver ligado.

## Estratégia comercial obrigatória

Não quero um sistema focado em agendar reuniões ou demonstrações.

**NÃO EXISTE ETAPA DE DEMONSTRAÇÃO COMERCIAL.**

O processo será:

1. Encontrar empresas que possam precisar do Agexa.
2. Analisar as necessidades de cada empresa.
3. Identificar oportunidades comerciais.
4. Preparar abordagens personalizadas.
5. Contactar potenciais clientes por canais autorizados ou responder aos interessados.
6. Conversar profissionalmente.
7. Explicar o Agexa.
8. Convencer o cliente do valor da plataforma.
9. Responder às objeções.
10. Despertar interesse em experimentar.
11. Enviar o link oficial de criação de conta.
12. Informar que pode testar o Agexa durante 7 dias gratuitamente.
13. Assim que o link for enviado, encaminhar a conversa para mim, o CEO.
14. Notificar-me imediatamente no painel.
15. Permitir que eu continue a negociação pessoalmente.
16. Registar se o cliente criou conta e se posteriormente se tornou pagante.

A prioridade é gerar clientes reais, não simplesmente enviar muitas mensagens.

O sistema deve otimizar conversões verificadas e respeitar as regras de comunicação comercial.

**IMPORTANTE:** esta é uma integração experimental e não oficial. Existe risco de bloqueio ou restrição do número pela Meta.

Implementar:

- Botão "Ligar WhatsApp".
- QR Code de autenticação.
- Estado da conexão.
- Botão "Desligar".
- Recuperação de sessão, quando possível.
- Caixa de entrada.
- Lista de conversas.
- Histórico de mensagens.

- Modo de atendimento assistido.

Os agentes podem analisar conversas e sugerir respostas, mas não enviam mensagens.

Os agentes preparam respostas e o CEO pode aprovar o envio.

A integração experimental deve utilizar uma sessão associada e não solicitar migração exclusiva do número para uma API.

Não garantir que uma sessão não oficial será permanente ou que o número nunca será restringido.

Criar uma interface modular para integração futura com a Cloud API oficial da Meta.
